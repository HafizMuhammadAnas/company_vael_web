# VaelKode brand kit

Logo assets generated from the approved VaelKode mark (fluid glowing V + wordmark).

## Verdict

The logo is a strong fit: distinctive, tech-forward, and memorable. Use the photographic PNG mark for brand moments; use the simplified SVG for scalable UI.

## Quick open

Open `lockup-board.html` in a browser to compare **16 lockup styles** (stacked, horizontal, compact, tagline, light/dark, mono, app icon, naming treatments).

## Folders

| Path | Contents |
|------|----------|
| `png/transparent/` | Mark, wordmarks, lockups on transparent |
| `png/dark/` | Same lockups on black + OG image |
| `png/light/` | Lockups tuned for light backgrounds |
| `png/app-icons/` | 16–1024px icons + favicon-32 |
| `svg/` | Vector mark, lockups, mono, app icon |

## Lockups

1. **Mark only** — favicon, avatar  
2. **Stacked** — hero / splash (primary brand)  
3. **Horizontal** — website header  
4. **Compact horizontal** — mobile nav / email  
5. **Horizontal + tagline** — proposals / letterhead  
6. **Wordmark only** — when mark already shown  
7. **Mono mark** — print / embroidery  

## Note on vector fidelity

The original mark is a complex luminous fibre/ribbon render. `svg/mark.svg` is a **simplified gradient vector** suitable for UI. For packaging or large print matching the original exactly, keep the transparent PNG, or have a designer redraw as mesh/fibre vectors.
