Recommended usage

  • Website header: #3 or #4 horizontal
  • Hero / splash: #2 stacked
  • Favicon / PWA: #1 or #12 mark only
  • Social share: dark OG image in png/dark/og-image.png
  • Print / mono: #11

Suggestions

  • Keep CamelCase VaelKode — it reads as brand, not a misspelling of “code”.
  • On light backgrounds, darken the wordmark (already done in light kit).
  • Below ~24px, use mark-only — fine glow detail disappears.
  • For true perfect vector of the fibrous glow, commission a mesh/fibre redraw in Illustrator; the SVG here is a clean working approximation.
  • Replace the old gear glyph currently in the site with this mark when you’re ready.
